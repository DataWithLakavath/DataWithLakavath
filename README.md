# 👨‍💻 About Me

I'm a **Senior Data Engineer** focused on building reliable, scalable, and production-ready data platforms.

I enjoy solving the problems that happen between **raw data and useful data** — ingesting information from different systems, building ETL/ELT pipelines, processing large datasets, improving data quality, and delivering trusted datasets for analytics and downstream applications.

My experience spans **financial services, healthcare, retail/e-commerce, cloud data engineering, batch processing, real-time streaming, data warehousing, lakehouse architecture, and business intelligence**.

### ⚡ What I Work On

🔹 Building scalable batch and real-time data pipelines  
🔹 Processing large datasets using **Spark, PySpark & Databricks**  
🔹 Designing **Data Lakes, Lakehouses & Data Warehouses**  
🔹 Building **Medallion Architecture - Bronze, Silver & Gold**  
🔹 Developing cloud data solutions across **AWS, Azure & GCP**  
🔹 Building modern platforms with **Snowflake & Microsoft Fabric**  
🔹 Orchestrating ETL/ELT workflows using **Airflow, dbt, ADF & Glue**  
🔹 Implementing **data quality, validation, lineage & governance**  
🔹 Designing dimensional models and analytics-ready datasets  
🔹 Automating deployments through **CI/CD & Infrastructure as Code**
